# my-blog-back-app

## Бэкенд приложения-блога с использованием Spring Framework

### Запуск бэкенда
1. Перейдите в директорию проекта, где находится файл `docker-compose.yaml`
2. Запустите сервисы в фоновом режиме: `docker compose up -d`
3. Убедитесь, что контейнер с PostgreSQL запущен: `docker ps`


### Запуск тестов
Проект содержит 155 тестов, использующих `PostgreSQLContainer` из Testcontainers.
Для работы тестов требуется установленный Docker — он нужен для запуска контейнера с PostgreSQL. 

Тесты покрывают:
* успешные сценарии и граничные значения;
* валидацию входных данных и ответы на невалидные запросы;
* CRUD‑операции, пагинацию и поиск;
* обработку исключений (в том числе через @RestControllerAdvice).

Для запуска тестов:
1. Перейдите в корневую директорию проекта
2. Соберите проект и запустите тесты: `mvn clean test`



### Выявленные аномалии фронта

#### 1. При попытке обновить пост без изменения картинки фронт отображает ошибку. 
Это некорректно: пользователь должен иметь возможность, например, обновить только название поста.


#### 2. Получение комментариев поста `GET /{postId}/comments`
После добавления поста и при переходе на страницу поста, фронт не сразу определяет `postId` и отправляет запрос с `undefined` вместо `postId` для получения комментариев

**Пример ошибочного запроса:**
```http
http://localhost:8080/api/posts/undefined/comments
```
Поэтому при первом запросе принял решение в ответе отправлять `400 Bad Request` 


#### 3. Обновление комментария `PUT /{postId}/comments/{commentId}`

При обновлении комментария фронт подставляет в URL `commentId` вместо `postId`. При этом в теле запроса `postId` указан верно. И при удалении комментария `postId` подставляется корректно.

**Пример ошибочного запроса при удалении 4-ого комментария 1-ого поста:**
```http
http://localhost:8080/api/posts/4/comments/4
```

**Тело запроса:**
```json
{
  "id": 4,
  "text": "Новый комментарий",
  "postId": 1
}
```

Поэтому также принял решение в ответе отправлять `400 Bad Request` с телом 
```json
{
    "message": "Несовпадение идентификаторов postId - в теле запроса: 1, но в url запроса: 4"
}
```
